# Sicherheit

Sicherheitsprobleme bitte nicht als öffentliche Diskussion mit Beispieldateien melden, wenn diese persönliche Daten enthalten. Kontaktmöglichkeiten stehen auf [rodneyswelten.de](https://rodneyswelten.de).

Videodateien werden lokal analysiert. Das Programm lädt keine Medieninhalte zu einem Server hoch.

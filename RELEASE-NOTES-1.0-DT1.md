# Video Codec Scanner Portable 1.0 Development Test 1

Initial PortableApps.com development test release.

## Features

- German Windows interface with drag and drop
- Local video analysis using the bundled ffprobe component
- Video and audio codecs, bitrates, resolution, aspect ratio, frame rate, and duration
- File size, container information, stream details, and subtitle tracks
- Understandable compression metrics
- Portable settings stored in the PortableApps `Data` directory
- No administrator rights required
- No separate Python, FFmpeg, or MediaInfo installation required
